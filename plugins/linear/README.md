# Linear 플러그인

Linear MCP 서버의 도구 정의와 명령 매핑을 제공합니다.
저장소 루트에서 실행하십시오.

```sh
bun run cli login linear
bun run generate linear
bun run cli linear --help
```

`LINEAR_MCP_TOKEN`은 저장한 토큰보다 우선합니다. `LINEAR_MCP_URL`로 서버 URL을 바꿀 수 있습니다.
[공통 사용법](../../apps/cli/README.md)과 [플러그인 개발 안내](../README.md)를 참고하십시오.
