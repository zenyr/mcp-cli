# Security policy

## Supported versions

Security fixes target the latest commit on `main`. Update to the latest revision
before checking whether an issue is still present.

## Reporting a vulnerability

Do not disclose vulnerabilities, credentials, or exploit details in public issues
or pull requests.

Email [zenyr@zenyr.com](mailto:zenyr@zenyr.com) to report a vulnerability privately.
When GitHub private vulnerability reporting is available, you can also use
[Report a vulnerability](https://github.com/zenyr/mcp-cli/security/advisories/new).

Include the affected commit, operating system, reproduction steps, and expected
security impact. Remove real tokens, personal data, and unrelated private files
from examples. Coordinate public disclosure with the maintainer after a fix is
available.
